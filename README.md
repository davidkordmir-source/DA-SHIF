# هم‌شیفت — مدیریت آفلاین شیفت پرسنل

برنامهٔ فارسی و راست‌به‌چپ برای تقسیم شیفت‌های **روزانه با ۲ نفر اصلی و ۲ نفر رزرو**. تعداد نفرات و فاصلهٔ استراحت قابل تنظیم‌اند.

## دانلود مستقیم

[دانلود بستهٔ آفلاین هم‌شیفت (ZIP)](https://github.com/davidkordmir-source/DA-SHIF/raw/refs/heads/main/downloads/hamshift-offline.zip)

بسته را استخراج کنید و فایل `hamshift.html` را در مرورگر باز کنید. در ویندوز می‌توانید روی `شروع-هم‌شیفت.bat` نیز دوبار کلیک کنید. برنامه به نصب وابستگی یا اینترنت نیاز ندارد.

## اجرای نسخهٔ آفلاین

فایل `dist/index.html` خروجی کامل برنامه است؛ آن را روی دستگاه خود نگه دارید و با مرورگر جدید Chrome، Edge یا Firefox باز کنید. این فایل شامل کد، فونت فارسی، تقویم و ابزار اکسل است؛ پس از ساخت، نیازی به Node.js، حساب کاربری، اینترنت یا سرور خارجی ندارد. برای باز کردن خودکار در ویندوز می‌توانید از `release/شروع-هم‌شیفت.bat` در بستهٔ انتشار استفاده کنید.

اطلاعات در حافظهٔ محلی همان مرورگر ذخیره می‌شوند. مسیر فایل و مرورگر را ثابت نگه دارید؛ رفتار ذخیره‌سازی `file://` بین مرورگرها متفاوت است. حالت خصوصی مناسب نگهداری سوابق نیست. **به‌صورت منظم از تنظیمات، پشتیبان کامل JSON دریافت کنید.** پاک کردن داده‌های مرورگر، تغییر نام یا جابه‌جایی فایل ممکن است دسترسی به ذخیرهٔ قبلی را تغییر دهد؛ با فایل پشتیبان می‌توانید اطلاعات را بازیابی کنید.

اگر سیاست دستگاه اجرای فایل محلی را مسدود می‌کند، فایل را با یک وب‌سرور محلی اجرا کنید؛ مثلاً `python3 -m http.server 8080 --directory dist` و سپس `http://localhost:8080`. این روش هم به اینترنت نیاز ندارد. آدرس و پورت را برای دسترسی به همان داده‌ها ثابت نگه دارید.

## قابلیت‌ها

- ورود فایل `.xlsx` با پیش‌نمایش، تشخیص خطا و نام/کد تکراری؛ دریافت الگوی اکسل از داخل برنامه. فایل‌های قدیمی `.xls` باید ابتدا در اکسل به `.xlsx` تبدیل شوند.
- مدیریت پرسنل، غیرفعال‌سازی با حفظ سابقه و تعریف افرادی که فقط در رزرو قرار می‌گیرند.
- تقویم شمسی با نمایش شمارهٔ روز میلادی و قمری؛ جزئیات هر روز شامل هر سه تاریخ است. بازهٔ ماه در تقویم همیشه یک ماه شمسی است.
- جمعه‌ها، تعطیلات ثابت شمسی ایران و مناسبت‌های رایج شمسی/قمری؛ افزودن مناسبت و تعطیلی سازمانی.
- شیفت‌بندی با در نظر گرفتن تعداد کل شیفت، تعطیلات، جمعه‌ها، روز هفته، استراحت و سابقهٔ ماه‌های ذخیره‌شده.
- جلوگیری از نقش هم‌زمان اصلی و رزرو برای یک نفر در یک روز.
- ثبت حضور، غیبت موجه/غیرموجه، توضیحات و انتخاب جایگزین از رزرو همان روز، بدون پاک کردن نام نیروی غایب.
- حضور نیروی جایگزین و غیبت نیروی اصلی در بار کاری برنامه‌ریزی آینده لحاظ می‌شوند.
- تبادل شیفت دو روز یا تبادل اصلی و رزرو در همان روز؛ ثبت دائمی نام افراد، تاریخ‌ها، توضیح و زمان ثبت. بررسی تداخل و استراحت پیش از ذخیره.
- پروندهٔ هر فرد: شیفت‌های برنامه‌ریزی‌شده، حضور ثبت‌شده، غیبت‌ها، سوابق و تعداد روز تا شیفت بعدی.
- گزارش عددی عدالت و خروجی اکسل با سه برگهٔ برنامه، گزارش و جابه‌جایی‌ها.
- پشتیبان‌گیری و بازیابی کامل با کنترل سازگاری داده‌ها و تأیید پیش از جایگزینی.
- نمای مناسب تلفن همراه و راهنمای فارسی داخل برنامه.

### نکات تقویم و برنامه‌ریزی

تقویم قمری از `Intl.DateTimeFormat` با الگوریتم `islamic-civil` استفاده می‌کند و **تقویم رسمیِ مبتنی بر رؤیت هلال نیست**. تعطیلات قمری ممکن است با اعلام رسمی ایران تفاوت داشته باشند. در تنظیمات، اصلاح سراسری تا دو روز و مناسبت سفارشی با «جایگزینی تعطیلی محاسباتی» وجود دارد: روز محاسباتی اشتباه را عادی کنید و تعطیلی رسمی را در روز صحیح ثبت کنید. مناسبت‌ها شامل موارد اصلی‌اند و فهرست جامع تمام مناسبت‌های رسمی و غیررسمی نیستند. تعطیلی‌های موردی کشور باید محلی اضافه شوند.

برنامه‌ریز یک روش ابتکاری قطعی است؛ برابری ریاضی در تمام محدودیت‌ها تضمین نمی‌شود. ابتدا روزهای تعطیل و سپس عادی تخصیص داده می‌شوند؛ سهم تاریخی تعطیلات، جمعه‌ها و روزهای هفته، تعداد کل و استراحت در انتخاب اثر دارند. اگر استراحت با تعداد نفرات موجود قابل رعایت نباشد، هشدار ذخیره و نمایش داده می‌شود. رزروها با اولویت فاصلهٔ استراحت و سپس تعداد نوبت‌های رزرو انتخاب می‌شوند. در صورت تداخل استراحت، جایگزینی واقعی آن رزرو رد می‌شود.

برنامهٔ ماه دارای حضور/غیبت یا سابقهٔ جابه‌جایی بازتولید نمی‌شود تا سوابق از بین نروند. تغییر تنظیمات، اسامی فعال یا تعطیلات، برنامه‌های قبلی را خودکار بازنویسی نمی‌کند. تعطیلات در گزارش با تنظیمات فعلی محاسبه می‌شوند. برای توزیع مجدد باید برنامهٔ بدون سابقه را دوباره بسازید. غیرفعال‌سازی هم شیفت قبلی را حذف نمی‌کند؛ ابتدا تکلیف آن شیفت‌ها را مشخص کنید.

## توسعه

پیش‌نیاز: Node.js 22 یا جدیدتر و npm. از checkout موجود استفاده کنید؛ محیط هر وظیفه مستقل است و به worktree اضافی نیاز ندارد.

```bash
cd /workspace/DA-SHIF
npm ci --cache /tmp/hamshift-npm-cache
npm run dev -- --port 5173
```

```bash
npm test              # تقویم، عدالت، استراحت، سوابق و اعتبارسنجی پشتیبان
npm run build         # TypeScript و تولید فایل آفلاین مستقل
npm run release       # ساخت نسخه آفلاین و بسته ZIP (نیازمند Python 3 برای بسته‌بندی)
npm run test:e2e      # آزمون واقعی مرورگر، اکسل، حضور، جابه‌جایی و حالت آفلاین
npm run preview -- --port 4173
```

آزمون مرورگر به Chromium نیاز دارد؛ مسیر پیش‌فرض این محیط `/usr/bin/chromium` است. در محیط توسعهٔ دیگر می‌توانید متغیر `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` را روی مسیر مرورگر تنظیم کنید یا Chromium مربوط به Playwright را نصب کنید.

در Chromium مدیریت‌شدهٔ محیط ابری، باز کردن مستقیم `file://` با سیاست سازمانی مسدود است. آزمون آفلاین همان فایل نهایی را از حافظه در اختیار مرورگر قرار می‌دهد، در حالی که ارتباط شبکهٔ مرورگر قطع است؛ درخواست خارجی نیز کنترل می‌شود. این آزمون به‌معنی تأیید سیاست فایل محلی دستگاه کاربر نیست.

تمام وابستگی‌ها هنگام ساخت محلی بسته‌بندی می‌شوند؛ برنامهٔ نهایی از CDN، API تعطیلات، ابزار رهگیری یا فونت آنلاین استفاده نمی‌کند.
