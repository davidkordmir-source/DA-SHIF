# هم‌شیفت ۲.۱ — نرم‌افزار مستقل ویندوز برای مدیریت شیفت پرسنل

[دانلود مستقیم نصب‌کنندهٔ ویندوز ۶۴ بیتی](https://github.com/davidkordmir-source/DA-SHIF/raw/refs/heads/main/downloads/Hamshift-Setup-2.1.0-x64.exe)

## نصب و اجرا

فایل `Hamshift-Setup-2.1.0-x64.exe` را دانلود و اجرا کنید. مسیر نصب را انتخاب کنید؛ میانبر دارای لوگوی هم‌شیفت در دسکتاپ و منوی Start ساخته می‌شود. اجرای برنامه به مرورگر، Node.js یا اینترنت نیاز ندارد. زمان به‌روزرسانی برنامه را ببندید.

- سیستم مورد نیاز: **ویندوز ۱۰ یا ۱۱، نسخهٔ ۶۴ بیتی (x64)**.
- نصب برای حساب فعلی انجام می‌شود؛ مسیر پیش‌فرض `%LOCALAPPDATA%\Programs\Hamshift` است.
- تمام وابستگی‌های اجرا، فونت‌ها، تقویم و ابزار اکسل در نصب‌کننده قرار دارند.
- داده‌ها در `%APPDATA%\Hamshift\hamshift-data.json` ذخیره می‌شوند، نه در مرورگر. یک نسخهٔ قبلی نیز با پسوند `.bak` حفظ می‌شود. همچنان از داخل تنظیمات، پشتیبان JSON دریافت کنید.
- حذف برنامه، اطلاعات پرسنل را از پوشهٔ کاربری پاک نمی‌کند. حذف‌کننده فقط فایل‌های نصب‌شدهٔ برنامه را حذف می‌کند و فایل‌های شخصی مانند لوگو را نگه می‌دارد.
- برای انتقال داده از نسخهٔ قدیمی مرورگری، در آن نسخه پشتیبان JSON بگیرید و در نسخهٔ نصبی از تنظیمات بازیابی کنید.
- نصب‌کننده امضای تجاری Authenticode ندارد؛ ممکن است ویندوز ناشر را ناشناس نشان دهد. فایل و SHA-256 منتشرشده متعلق به همین مخزن هستند.

## ظاهر و لوگوی شروع

از **تنظیمات > رنگ و حال هم‌شیفت** بین **۱۴ طرح** انتخاب کنید: زمردی، بنفش، اقیانوسی، طلایی، رز، شب آرام، گرافیت، دفتر کاهی، شفق قطبی، کبالت، ماسه و قهوه، یاقوت، آبنباتی و نئون. طرح‌های جدید علاوه بر رنگ، فرم کارت، منو، گوشه‌ها و بافت پس‌زمینه را تغییر می‌دهند. **۸ فونت فارسی** وزیرمتن، استعداد، نوتو عربی، ریدکس، لاله‌زار، مرکزی، بالو و امیری همراه برنامه‌اند. متن نمونه را برای مقایسهٔ واقعی فونت‌ها تغییر دهید. تم و فونت بدون اینترنت تغییر می‌کنند و همراه پشتیبان حفظ می‌شوند. لوگوی اختصاصی برنامه در فایل اجرایی، نصب‌کننده، پنجره و میانبر دسکتاپ یکسان است.

برای نمایش لوگوی دلخواه پیش از باز شدن برنامه:

1. در تنظیمات روی **پوشهٔ نصب** بزنید یا پوشهٔ شامل `Hamshift.exe` را باز کنید.
2. تصویر خود را با نام **`splash-logo.png`** کنار فایل اجرایی قرار دهید.
3. برنامه را ببندید و دوباره اجرا کنید؛ لوگو در صفحهٔ لودینگ خوانده می‌شود.

نام‌های `splash-logo.jpg`، `splash-logo.jpeg` و `splash-logo.webp` نیز پشتیبانی می‌شوند؛ اولویت با PNG، سپس JPG/JPEG و WEBP است. حداکثر حجم ۵ مگابایت است. تصویر PNG شفاف پیشنهاد می‌شود. اگر فایل وجود نداشته باشد یا قابل خواندن نباشد، لوگوی پیش‌فرض نمایش داده می‌شود.

دکمهٔ **انتخاب لوگوی شروع** همین کار را از داخل برنامه انجام می‌دهد و تصویر انتخابی را به PNG تبدیل می‌کند. برای جایگزینی یک لوگوی موجود تأیید گرفته می‌شود. تغییر تصویر لودینگ، آیکون ثابت نصب و دسکتاپ را تغییر نمی‌دهد.

## قابلیت‌ها

- ورود فایل `.xlsx` با پیش‌نمایش، تشخیص خطا و نام/کد تکراری؛ دریافت الگوی اکسل از داخل برنامه. فایل‌های قدیمی `.xls` باید ابتدا در اکسل به `.xlsx` تبدیل شوند.
- مدیریت پرسنل، غیرفعال‌سازی با حفظ سابقه و تعریف افرادی که فقط در رزرو قرار می‌گیرند.
- تقویم شمسی با نمایش شمارهٔ روز میلادی و قمری؛ جزئیات هر روز شامل هر سه تاریخ است. بازهٔ ماه در تقویم همیشه یک ماه شمسی است.
- جمعه‌ها، تعطیلات ثابت شمسی ایران و مناسبت‌های رایج شمسی/قمری؛ افزودن مناسبت و تعطیلی سازمانی.
- شیفت‌بندی با در نظر گرفتن تعداد کل شیفت، تعطیلات، جمعه‌ها، روز هفته، استراحت و سابقهٔ ماه‌های ذخیره‌شده.
- جلوگیری از نقش هم‌زمان اصلی و رزرو برای یک نفر در یک روز.
- ثبت حضور، غیبت موجه/غیرموجه، توضیحات و انتخاب جایگزین از رزرو همان روز، بدون پاک کردن نام نیروی غایب.
- حضور نیروی جایگزین و غیبت نیروی اصلی در بار کاری برنامه‌ریزی آینده لحاظ می‌شوند.
- تبادل شیفت دو روز یا تبادل اصلی و رزرو در همان روز؛ ثبت دائمی نام افراد، تاریخ‌ها، توضیح و زمان ثبت. بررسی تداخل و استراحت پیش از ذخیره.
- پروندهٔ هر فرد: شیفت‌های برنامه‌ریزی‌شده، حضور ثبت‌شده، غیبت‌ها، سوابق و تعداد روز تا شیفت بعدی.
- گزارش عددی عدالت و خروجی اکسل با سه برگهٔ برنامه، گزارش و جابه‌جایی‌ها.
- پشتیبان‌گیری و بازیابی کامل با کنترل سازگاری داده‌ها و تأیید پیش از جایگزینی.
- چهارده تم با فرم‌های متفاوت، هشت فونت فارسی، صفحهٔ شروع با لوگوی قابل تغییر و راهنمای فارسی داخل برنامه.

### نکات تقویم و برنامه‌ریزی

در نسخهٔ **۲.۱**، تاریخ قمری در بازهٔ **۱۱ سپتامبر ۲۰۱۸ تا ۲۰ مارس ۲۰۲۷** از جدول شروع ماه‌های ایران خوانده می‌شود. انتهای جدول برابر پایان سال **۱۴۰۵** است. داده‌های ۱۴۰۵ با تطبیق‌های تقویم منتشرشدهٔ ایران بررسی شده‌اند؛ برای نمونه، **شهادت حضرت فاطمه، جمعه ۲۲ آبان ۱۴۰۵ / ۱۳ نوامبر ۲۰۲۶ / ۳ جمادی‌الثانی ۱۴۴۸** است. این تعطیلی در شنبه ۲۳ آبان نمایش داده نمی‌شود.

۴۴۵ مناسبت ایران در سه تقویم شمسی، قمری و میلادی همراه برنامه‌اند؛ قواعد آخر ماه، دومین جمعه و آخرین جمعه نیز پشتیبانی می‌شوند. منابع، محدودهٔ پوشش و تاریخ به‌روزرسانی در [مستند داده‌های تقویم](docs/calendar-data.md) ثبت شده‌اند. داده‌ها و فونت‌ها کاملاً آفلاین هستند.

**خارج از محدودهٔ جدول، تاریخ قمری برآوردی است** و در برنامه همین وضعیت نمایش داده می‌شود. اصلاح دستی قمری فقط برای این بازه‌ها اعمال می‌شود و تاریخ‌های جدول را جابه‌جا نمی‌کند؛ مقدار تنظیم قدیمی محفوظ می‌ماند. تعطیلی‌های موردی یا تغییر اعلام رسمی را می‌توان با مناسبت سفارشی ثبت کرد؛ اصلاح شخصی بر دادهٔ همراه برنامه اولویت دارد. به‌روزرسانی تقویم، افراد و شیفت‌های قبلی را جابه‌جا نمی‌کند. تاریخ امروز نیز در نیمه‌شب تهران و هنگام برگشت به برنامه تازه می‌شود.

برنامه‌ریز یک روش ابتکاری قطعی است؛ برابری ریاضی در تمام محدودیت‌ها تضمین نمی‌شود. ابتدا روزهای تعطیل و سپس عادی تخصیص داده می‌شوند؛ سهم تاریخی تعطیلات، جمعه‌ها و روزهای هفته، تعداد کل و استراحت در انتخاب اثر دارند. اگر استراحت با تعداد نفرات موجود قابل رعایت نباشد، هشدار ذخیره و نمایش داده می‌شود. رزروها با اولویت فاصلهٔ استراحت و سپس تعداد نوبت‌های رزرو انتخاب می‌شوند. در صورت تداخل استراحت، جایگزینی واقعی آن رزرو رد می‌شود.

برنامهٔ ماه دارای حضور/غیبت یا سابقهٔ جابه‌جایی بازتولید نمی‌شود تا سوابق از بین نروند. تغییر تنظیمات، اسامی فعال یا تعطیلات، برنامه‌های قبلی را خودکار بازنویسی نمی‌کند. تعطیلات در گزارش با تنظیمات فعلی محاسبه می‌شوند. برای توزیع مجدد باید برنامهٔ بدون سابقه را دوباره بسازید. غیرفعال‌سازی هم شیفت قبلی را حذف نمی‌کند؛ ابتدا تکلیف آن شیفت‌ها را مشخص کنید.

## توسعه و ساخت

Node.js 22.12 یا جدیدتر لازم است. از checkout موجود استفاده کنید؛ به worktree جدید نیاز نیست.

```bash
npm ci
npx install-electron --no
npm run desktop        # ساخت رابط و اجرای برنامهٔ مستقل روی سیستم توسعه
npm run dev            # پیش‌نمایش رابط برای توسعه
npm test               # آزمون تقویم، شیفت‌بندی و پشتیبان
npm run test:desktop   # آزمون ذخیره‌سازی فایل و انتخاب لوگوی شروع
npm run test:e2e       # آزمون مرورگر و برنامهٔ مستقل Electron
npm run desktop:build  # بستهٔ Windows x64 و نصب‌کننده NSIS
```

خروجی نصب‌کننده: `out/Hamshift-Setup-2.1.0-x64.exe`. ساخت روی لینوکس نیز پشتیبانی می‌شود: ابزار NSIS رسمی و Electron با بررسی checksum دریافت می‌شوند؛ آیکون و metadata ویندوز با `resedit` و بدون اجرای فایل ناشناس در Wine تنظیم می‌شوند. نسخه‌های ابزار در lockfile و پیکربندی ساخت ثبت شده‌اند. برنامهٔ توزیع‌شده تمام runtime را همراه دارد.

در این محیط ابری برای مسیرهای قابل نوشتن و پراکسی، از این دستور استفاده می‌شود:

```bash
NODE_USE_ENV_PROXY=1 ELECTRON_BUILDER_CACHE=/tmp/hamshift-builder-cache XDG_CACHE_HOME=/tmp/hamshift-cache npm run desktop:build
```

آزمون Electron از runtime لینوکسی و صفحهٔ مجازی Ozone استفاده می‌کند؛ این آزمون، اجرای واقعی نصب‌کننده در ویندوز را تأیید نمی‌کند. آزمون‌های ساخت شامل بررسی ساختار PE، منابع آیکون، محتوای بسته و سلامت فایل نصب نیز هستند. اسکریپت `scripts/windows-install-smoke.ps1` برای بررسی نصب، میانبر و حذف در یک سیستم Windows آزمایشی ارائه شده است.

رابط نهایی از CDN، API تعطیلات، رهگیری یا فونت آنلاین استفاده نمی‌کند. پوستهٔ دسکتاپ درخواست‌های شبکه را نیز مسدود می‌کند. دسترسی به Node.js در رابط غیرفعال و preload محدود است. حافظه و دسترسی لوگو در پردازش اصلی مدیریت می‌شوند.
