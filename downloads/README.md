# دریافت هم‌شیفت

نسخهٔ فعلی **نصب‌شوندهٔ ویندوز**:

[Hamshift-Setup-2.3.0-x64.exe](https://github.com/davidkordmir-source/DA-SHIF/raw/refs/heads/codex/hamshift-2.3.0/downloads/Hamshift-Setup-2.3.0-x64.exe)

برای ویندوز ۱۰ و ۱۱، معماری x64. با اجرای فایل نصب، میانبر دارای لوگوی برنامه روی دسکتاپ ایجاد می‌شود. برنامه به مرورگر یا اینترنت نیاز ندارد.

این نسخه اصلاح تقویم ۱۴۰۵ (شهادت حضرت فاطمه در جمعه ۲۲ آبان)، ۱۴ تم و ۸ فونت فارسی دارد. رزروها را از کل پرسنل به دلخواه تغییر دهید؛ سابقهٔ ماه‌های ذخیره‌شده در عدالت شیفت‌بندی لحاظ می‌شود. در تنظیمات، تم و فونت را تغییر دهید. برای تغییر لوگوی لودینگ، `splash-logo.png` را کنار `Hamshift.exe` بگذارید یا از دکمهٔ انتخاب لوگو استفاده کنید.

فایل `hamshift-offline.zip` مربوط به نسخهٔ قدیمی مرورگری است و نصب‌کنندهٔ ویندوز نیست.

نسخهٔ ۲.۳ فهرست‌های نام‌دار، حذف امن با ثبت حق شیفت و استراحت، بازنشانی محافظت‌شده، موقعیت‌های خدمت، یادآوری وابسته به فهرست، تنظیم اندازهٔ فونت، انتخاب بازه از تقویم شمسی و گزارش‌گیری فیلترشده با اکسل رنگی دارد. برای دریافت یادآوری، برنامه باید باز باشد.
