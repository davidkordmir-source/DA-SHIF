# دریافت هم‌شیفت

نسخهٔ فعلی **نصب‌شوندهٔ ویندوز**:

[Hamshift-Setup-2.0.0-x64.exe](https://github.com/davidkordmir-source/DA-SHIF/raw/refs/heads/main/downloads/Hamshift-Setup-2.0.0-x64.exe)

برای ویندوز ۱۰ و ۱۱، معماری x64. با اجرای فایل نصب، میانبر دارای لوگوی برنامه روی دسکتاپ ایجاد می‌شود. برنامه به مرورگر یا اینترنت نیاز ندارد.

در تنظیمات، تم و فونت را تغییر دهید. برای تغییر لوگوی لودینگ، `splash-logo.png` را کنار `Hamshift.exe` بگذارید یا از دکمهٔ انتخاب لوگو استفاده کنید.

فایل `hamshift-offline.zip` مربوط به نسخهٔ قدیمی مرورگری است و نصب‌کنندهٔ ویندوز نیست.
